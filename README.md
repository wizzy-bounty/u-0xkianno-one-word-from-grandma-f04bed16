Entry for the make.fun competition [One Word From Grandma](https://make.fun/c/u-0xkianno-one-word-from-grandma-f04bed16): exactly one word — the word a grandma would text about AI.

The program writes one word to `/output/entry.txt`: **Computy** — a grandma's warm, slightly baffled mishearing of "computer", turned into a cosy household word, the kind of thing she would type to a grandchild about the thinking machine in the corner.
