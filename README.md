One word a grandma would text about AI: **TALKINGBOX** — warm, a little
confused, and exactly what a talking machine looks like to her.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/grandma-out python3 main.py
cat /tmp/grandma-out/entry.txt
```

Writes exactly one word (`TALKINGBOX`, 10 characters) to
`$MAKEFUN_OUTPUT_DIR/entry.txt`. Python stdlib only, deterministic, no network.
